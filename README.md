# Personal site

Jekyll site served by GitHub Pages. No build step needed: push to `main` and it deploys.

## Write a new post

1. Create `_posts/YYYY-MM-DD-short-english-slug.md`
2. Start it with:

   ```
   ---
   title: عنوان المقال
   lang: ar
   ---
   ```

   `lang: ar` switches the page to right-to-left. Leave it out for English posts.
3. Commit and push.

`_drafts/sample-arabic-post.md` is a template. Files in `_drafts/` are never published.
